- 자료 등록에 저장 위치(합본 / 세 위원회 / 기타 자료)를 추가하였습니다. 위원회 내부에서는 현재 위원회를 기본값으로 선택합니다.
- 기존 브라우저 자료 중 저장 위치가 없는 자료는 각 분류의 기타 자료에 표시합니다. 기존 저장소 이름과 버전은 유지합니다.
- 기본 포함 PDF는 documents 폴더에서 제공하며 브라우저 DB에 중복 저장하지 않습니다. 전체 백업은 직접 등록한 자료와 사업 수치를 보관합니다. 기본 포함 PDF를 근거로 한 사업 수치도 복원할 수 있습니다. 이 백업은 같은 기본 자료를 포함하는 본 버전에서 복원하십시오.

## 파일 구성과 실행

index.html / app.js / style.css / favicon.svg / background.png와 documents 폴더를 같은 루트 구조로 유지하십시오. 로컬에서는 Start.cmd 또는 npm start로 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. PDF는 원본과 바이트 단위로 동일합니다.

## GitHub와 Vercel 반영

이 폴더는 수정본이며 기존 GitHub/Vercel에는 아직 반영되지 않았습니다. ZIP 자체를 저장소에 올리지 마시고 압축을 푼 파일을 기존 저장소 루트에 반영하십시오. 기존 코드 파일은 교체하고 documents 폴더는 새로 추가합니다. Vercel 설정은 기존 vercel.json을 유지합니다.

두 PDF는 각각 약 32 MB, 48 MB입니다. GitHub 웹 화면의 파일 업로드 제한(파일당 25 MiB)을 넘으므로 GitHub Desktop 또는 Git 명령으로 커밋/푸시하십시오. 각 파일은 일반 Git의 파일당 100 MiB 제한보다 작습니다.

배포에 포함한 두 PDF는 배포 서버에서 제공됩니다. 화면의 자료 등록으로 나중에 추가하는 파일은 해당 브라우저에만 저장되며 GitHub/Vercel로 자동 업로드되지 않습니다. 다른 기기에서도 기본 제공되게 하려면 파일을 documents에 추가하고 app.js 상단 bundledDocs 목록에 메타데이터를 추가하여 재배포하십시오.

## 기존 기능과 보관 주의사항

- 기준연도를 선택하면 해당 연도와 앞선 2개 연도를 조회합니다. 2026 기준으로 2024~2026 자료가 표시됩니다.
- 사업 수치는 천원 단위로 직접 입력하며, 같은 사업코드·부서·회계·연도로 중복 입력하지 않습니다.
- PDF/HWP 원문 자동 분석은 구현되지 않았습니다. 증감률은 (당해연도-전년도)/전년도*100, 집행률은 지출액/최종예산*100입니다. 공식 예산현액 기준 집행률과 다를 수 있습니다.
- 추가 등록 자료와 파일은 IndexedDB에 저장됩니다. 브라우저 데이터 삭제·주소 변경·기기 변경 시 같은 자료가 표시되지 않을 수 있으므로 정기적으로 전체 백업을 저장하십시오.
- 백업 복원은 현재 브라우저에 직접 등록한 자료와 사업 수치를 전체 교체합니다. 기본 포함 PDF는 프로그램 파일로 유지됩니다.
- 로그인·접근 통제·저장 암호화는 구현되지 않았습니다.
- 검증: JavaScript 구문 검사, 분류/위원회/연도/기존 자료/백업 근거 연결 로직 검사, 로컬 화면과 PDF 응답 검사.
